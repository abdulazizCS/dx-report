# قيمة وأثر 2026

كتاب تفاعلي لتقرير «قيمة وأثر» — التقرير الشامل لمنجزات التحول الرقمي في جامعة جازان (2006 – 2026م).

- `index.html`: صفحة الكتاب (تقليب من اليمين لليسار، فهرس، صور مصغّرة، تكبير، ملء الشاشة، روابط مثل `#page-11`).
- `pages/` و`thumbs/`: صور صفحات التقرير.
- `qeema-wa-athar-2026.pdf`: الملف الأصلي.
- `page-flip.browser.js`: مكتبة [StPageFlip](https://github.com/Nodlik/StPageFlip) (MIT).

للنشر: Settings ← Pages ← Deploy from a branch ← `main` / root.
